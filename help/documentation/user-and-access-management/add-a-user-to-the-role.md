# Hinzufügen von Benutzern zur Brand Concierge-Rolle

Weisen Sie Benutzende der Rolle zu, die die Berechtigung **Brand Concierge verwalten** enthält. Benutzende müssen auch Zugriff auf die Adobe Experience Platform-Organisation haben, bevor sie Brand Concierge verwenden können.

>[!PREREQUISITES]
>
>- Der Benutzer wurde der Adobe Experience Platform-Organisation hinzugefügt. Weitere Informationen finden Sie unter [Hinzufügen eines Benutzers zur Organisation](./add-a-user-to-the-org.md).
>- Es wurde eine Rolle mit **Berechtigung** Brand Concierge verwalten“ erstellt. Weitere Informationen finden Sie unter [Erstellen einer Rolle mit Brand Concierge-Berechtigung](./create-a-role.md).

## Benutzer aus der Rolle hinzufügen

1. Öffnen Sie in Adobe Experience Platform **Berechtigungen**.
1. Öffnen Sie die Rolle, die für den Zugriff auf Brand Concierge erstellt wurde.
1. Wählen Sie die **Benutzer** aus.
1. Suchen Sie nach dem Benutzer und fügen Sie ihn der Rolle hinzu.
1. Speichern Sie die Zuweisung, wenn Sie dazu aufgefordert werden.

## Hinzufügen einer Rolle aus einem Benutzerdatensatz

Sie können die Rolle auch aus dem Datensatz des Benutzers zuweisen:

1. Öffnen Sie den Datensatz des Benutzers.
1. Wählen Sie **Rolle hinzufügen** aus.
1. Suchen Sie nach der Rolle Brand Concierge .
1. Wählen Sie die Rolle aus und speichern Sie die Zuweisung.

## Zugriff überprüfen

Sobald sowohl die Einladung als auch die Rollenzuweisung abgeschlossen sind, kann der Benutzer:

- Melden Sie sich bei `experienceplatform.adobe.com` an.
- Zeigt die Organisationen an, auf die sie zugreifen können.
- Öffnen Sie **Brand Concierge**.
- Sandbox(s) anzeigen, die über die Rolle gewährt wurden.

Innerhalb einer Sandbox kann der Benutzer mehrere Concierge erstellen.
