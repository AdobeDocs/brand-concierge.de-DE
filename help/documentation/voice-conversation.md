# Sprachkonversationen in Brand Concierge aktivieren

Konfigurieren von Spracheingabe und gesprochenen Antworten für eine Brand Concierge. Sie können beide Funktionen unabhängig voneinander aktivieren oder beide für ein sprachbasiertes Gespräch aktivieren.

## Aktivieren von Voice

1. Wählen Sie auf dem **Home**-Bildschirm unter **Ihr Concierge** den gewünschten Concierge aus.

   SCREENSHOT

2. Wählen Sie die Registerkarte **Design** aus.
3. Wählen Sie im linken Menü **Sprache** aus.
4. Aktivieren Sie im Sprachbedienfeld die gewünschten Optionen:
   - **Diktat** - Zeichnet auf, was der Benutzer in Text sagt.
   - **Sprachmodus** — Liest die Antworten des Concierge laut vor.
5. Wählen **unten** Sprachbedienfeld „Speichern“ aus. **Speichern** ist erst verfügbar, wenn Sie eine Einstellung ändern.

Beide Optionen sind standardmäßig deaktiviert. Sowohl für gesprochene Eingabe als auch für gesprochene Antworten aktivieren.

## Aktivieren und Verwenden von Sprachkonversationen in Adobe Brand Concierge

In Adobe Brand Concierge-Sprachgesprächen können Besucher mit einem Concierge sprechen, anstatt zu tippen. Der Sprachmodus unterstützt Freisprech-Interaktionen und hält das Erlebnis multimodal: Der Concierge kann weiterhin Text, Bilder und Links bereitstellen.

## Sprachmodus aktivieren

1. Öffnen Sie die Concierge-Verwaltung und wählen Sie den Concierge aus, den Sie konfigurieren möchten.
2. Schalten Sie **Sprachmodus** ein.
3. Wenn Sie zum ersten Mal eine Stimme verwenden, lesen Sie die Datenschutzerklärung, die im Erlebnis angezeigt wird, bevor Sie fortfahren.

Welche Bedienelemente verfügbar sind, hängt von der Konfiguration Ihres Concierges ab.

## Sprachgespräch starten

Wenn der Voice Mode aktiviert ist, sprechen Sie natürlich mit dem Concierge. Die automatische Spracherkennung startet und stoppt das Hören, ohne dass Sie für jede Runde eine Taste drücken müssen.

Sie können das Gespräch mit weiterführenden Fragen fortsetzen. Sprachgespräche unterstützen auch natürliche Unterbrechungen, während der Concierge spricht, sodass Sie erneut sprechen können, anstatt auf den Abschluss der Antwort zu warten.

## Abrufen von Text und visuellen Antworten

Der Sprachmodus beschränkt den Concierge nicht auf Audio. Während eines Sprachgesprächs kann der Concierge immer noch Text, Bilder und Links als Teil seiner Antwort zurückgeben.

## Sprachmodus deaktivieren

Wenn die Stimme für das Concierge-Erlebnis nicht mehr gewünscht wird, deaktivieren Sie **Sprachmodus** in der Concierge-Verwaltung.
